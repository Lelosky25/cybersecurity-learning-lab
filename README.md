# Raspberry Pi Cybersecurity Homelab

## Overview

Welcome to my Raspberry Pi Cybersecurity Homelab! This repository documents my journey of building and expanding a portable cybersecurity lab while developing hands-on skills in Linux, networking, virtualization, scripting, system administration, and cybersecurity.

This is a long-term project that will evolve as I complete coursework, earn certifications, build new services, and experiment with cybersecurity tools. My goal is not only to learn the technologies but also to document each project and the lessons learned along the way.

---

## Objectives

* Build a professional cybersecurity homelab
* Learn Linux system administration
* Develop networking knowledge and troubleshooting skills
* Learn Docker and containerized applications
* Deploy self-hosted services
* Practice offensive and defensive cybersecurity techniques
* Improve scripting and automation with Bash and Python
* Create a portfolio of documented projects and labs
