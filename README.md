# Cybersecurity Learning Lab — Project Photos

## Overview
This branch stores screenshots and visual evidence from my cybersecurity home lab projects. The images help demonstrate the configurations, commands, and results from my hands-on learning.

## Repository Organization
- `main` — Main portfolio page and featured projects.
- `project-docs` — Written documentation and technical explanations.
- `project-photos` — Screenshots and supporting visual evidence.

## Notes
Screenshots are included to support my written documentation. Before publishing images, I check that they do not expose passwords, private keys, IP addresses that should remain private, personal information, or other sensitive system details.

This branch will be updated as new lab projects are completed.
