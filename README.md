# Cybersecurity Learning Lab — Project Documentation

## Overview
This branch contains the written documentation for my cybersecurity home lab projects. I use these projects to develop practical Linux administration, system configuration, access management, and cybersecurity skills.

## Purpose
My goal is to build practical technical skills through hands-on projects, document what I learn, and create a portfolio that demonstrates my growth in cybersecurity.

## Branch Organization
- `main` — Overview of the lab and selected featured projects.
- `project-docs` — Written project documentation and technical notes.
- `project-photos` — Screenshots and visual evidence from completed projects.

*This repository is an ongoing learning project. Documentation will be updated as I build and improve my lab.*
